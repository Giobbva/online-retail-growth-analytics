# Data

The notebook expects these four CSV files in this folder, all prepared with **Route B** (purchases net of recorded credits) from the Online Retail II dataset:

| File | Used in | Content |
|---|---|---|
| `indicadores_diarios.csv` | I. Forecasting | Daily net revenue and orders, Dec 2009 – Dec 2011 |
| `indicadores_diarios_comparacion.csv` | I. Forecasting | Daily indicators used for comparison |
| `clientes_clasificacion.csv` | II. Repurchase | Recency, orders, spend and 90-day repurchase label per customer (reference date: July 1, 2011) |
| `clientes_rfm.csv` | III. Segmentation | Recency, frequency and monetary value per customer (reference date: Dec 10, 2011) |

Original source: [Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii), UCI Machine Learning Repository, CC BY 4.0.
